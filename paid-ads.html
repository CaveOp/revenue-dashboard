Import Cycle Data

Two downloads per billing cycle: the Google Ads campaigns report (spend per campaign) and the GA4 transactions export (each web booking's reservation number with its source and campaign). Bookings are matched to ResNexus by reservation number from the stays already on this dashboard. Neither file holds names, phone numbers or emails.
Cycles run from the 15th of one month through the 14th of the next. Choosing a file sets this from the file's date range.
The Overview page download is a .zip holding one CSV per card; choose the zip as it is and the Campaigns file inside is used.
If you downloaded the Transactions report twice, once with Session source / medium and once with Session campaign, choose both files. They are merged by Transaction ID.
Where to get each file
Google Ads · Overview download (.zip)
  1. In Google Ads, open the Overview page.
  2. Set the date range in the upper right to the cycle, the 15th through the 14th.
  3. Click the download icon and choose CSV. The download is a .zip named Overview_cards_csv(…); choose that zip above as it is. The Campaigns file inside carries Campaign Name, Cost and Conversions.
The Campaigns page also works: set the same date range, click the download icon above the table and choose .csv. That file carries whatever columns the table shows, so Clicks and Phone calls come through if they are in the table.
GA4 · transactions, the Reports route
  1. In GA4, open Reports › Monetization › Transactions.
  2. Set the date range in the upper right to the cycle.
  3. Click the + next to Transaction ID at the top of the table and add the secondary dimension Session source / medium.
  4. Click Share this report in the upper right, then Download file › Download CSV.
  5. Repeat steps 3 and 4 with Session campaign as the secondary dimension. A standard report takes one secondary dimension at a time, so this is two downloads. Choose both files above.
GA4 · transactions, the Explore route (one file)
  1. Click Explore in the left navigation and start a blank exploration (the Create icon).
  2. In the Variables panel, click + beside DIMENSIONS and import Transaction ID, Session source / medium and Session campaign; beside METRICS import Purchase revenue. Click IMPORT.
  3. Drag the three dimensions into Rows and the metric into Values.
  4. Set the date range at the top of the Variables panel to the cycle.
  5. Click the Export data icon in the upper right and choose CSV. Sheets, TSV and CSV exports contain all rows, not only the ones displayed.
The exploration can be saved and reused; only the date range changes each cycle.
Privacy: what gets saved to the sheet is, per campaign and cycle, the spend figures from Google Ads; and per web booking, the reservation number, date, source / medium, campaign and the revenue GA4 recorded. No names, phone numbers or emails are in either file.

Phone bookings and calls from ads are shown side by side with no link between them; GA4 has no record of phone bookings. Why a booking is missing from GA4 is not known from these files.
